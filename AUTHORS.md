# Authors

MailMate originated as a Team CipherSquad project for Code2Create 7.0.
Git history remains the authoritative record of individual contributions.

- Rupayan Chattaraj - original repository setup, early web interface, and
  local-time UI work.
- Sreyanko - early Dashboard and Overview frontend development and subsequent
  integration fixes.
- Kartikay - early Node, Supabase, and dashboard integration work, plus
  branding updates.
- Asmin Sinha - initial Express backend, Gmail OAuth, and Gemini service
  foundation.
- Priyam Trivedi - later Flask architecture, Gmail workspace, Kyle, Calendar
  intelligence, Work Agent, automations, voice, privacy controls, local
  compute, and extensive application and runtime stabilization.

This list identifies contribution areas and is not an ownership-percentage
statement. Historical commit authorship, timestamps, and identities are
preserved in Git.
