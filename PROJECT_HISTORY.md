# MailMate Project History

## Code2Create 7.0 - Team CipherSquad

MailMate originated as a collaborative Team CipherSquad hackathon project for
Code2Create 7.0.

The available Git history records Rupayan Chattaraj's original repository
setup and early web and local-time UI work; Sreyanko's early Dashboard and
Overview frontend development and later integration fixes; Kartikay's early
Node, Supabase, and dashboard integration work and branding updates; Asmin
Sinha's initial Express, Gmail OAuth, and Gemini backend foundation; and
Priyam Trivedi's early interface work and later integrated application
development.

## Continued Development

Development continued substantially after Code2Create. Later work included:

- migration to a Flask application architecture
- the integrated Gmail workspace
- the Kyle assistant, runtime, tools, and response surfaces
- Calendar intelligence and deadline handling
- the Work Agent and automation system
- Whisper, text-to-speech, and voice interaction
- privacy controls and minimized derived state
- local and Tailscale-connected compute
- synchronization and Gmail-to-Work reconciliation
- runtime, reliability, testing, and UI stabilization

Continued maintenance does not replace or transfer authorship of earlier
contributions. The Git graph remains the detailed historical record.

## Organization Era

Following the historical team repository period, active MailMate development
moved to a neutral GitHub organization so that continued development and
governance would not depend on an individual contributor's personal
repository.

The migration preserves the complete available historical Git record and does
not alter authorship of earlier work.
